# Cómo anunciar un evento en 4fps

Edita `eventos.json` (en la raíz del repo) y agrega un evento así:

```json
{
  "eventos": [
    {
      "nombre": "Panaquistán 3",
      "fecha": "2026-12-20T20:00:00-03:00",
      "descripcion": "Evento de supervivencia con premios."
    }
  ]
}
```

La tarjeta "Próximo evento" del Perfil solo aparece cuando hay un evento que todavía no pasa.
